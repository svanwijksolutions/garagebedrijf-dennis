# Garagebedrijf Dennis — demo-ontwerp

Ongevraagd, vrijblijvend websiteconcept voor Garagebedrijf Dennis (Goudlaan 63, Den Haag),
gemaakt door S. van Wijk Solutions.

- Losse HTML, CSS en JavaScript, geen framework en geen buildstap.
- Tweetalig (Nederlands en Engels) via een clientside taalswitcher, zonder aparte URL's per taal.
- Staat op `noindex, nofollow` en `robots.txt: Disallow: /`, dit is een proefversie en geen live site.
